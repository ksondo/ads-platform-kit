## Verification

The branch runs five GitHub check groups: Demo Portal (Docker/nginx smoke, unit tests, Chromium category journeys, screenshots), Business Opportunities (isolated PostgreSQL/seed/API and content policy), Identity, kit CI and full sample-product E2E.

The Demo Portal `ux-screenshots` job creates **60 PNGs**: before and after, five pages (home, Platforms, Commerce detail, Opportunities, Demo access), widths **360/768/1280**, and **EN/FR**. Baseline is the commit on `main`; after is the draft branch. Screenshots contain a deterministic local mock API and no live customer account data. They are attached to the pull request's **Actions > UX before-after EN-FR 360-768-1280 > artifacts** as `ads-portal-ux-before-after`. Separate `opportunities-interactive-browser` artifacts include desktop sector, regulator and mobile views. These are CI evidence, not proof of actual Contabo release. The screenshot test uses the existing strict Nginx CSP, rejects CSP-style console errors, and checks known English-only strings in FR.
