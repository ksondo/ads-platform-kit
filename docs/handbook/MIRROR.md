# This folder is a copy

The ADS Handbook (delivery handbook, platform requirements, UI/UX register, templates) is the standard for building every ADS app. It is kept in two places, as the owner decided on 18 October 2026:

- **Software Factory** `docs/handbook/` — the **source**. Software Factory uses it as the standard it builds apps with. Change the handbook there, through a pull request.
- **ads-platform-kit** `docs/handbook/` (this folder) — a **copy**, so the teams using the shared services read the same rules next to the code that implements them.

Copied from ksondo/Software-Factory at commit `75ba89c` on 18 October 2026. To refresh: `scripts/sync-handbook.sh <path-to-Software-Factory-clone>`. Do not edit files here directly.
